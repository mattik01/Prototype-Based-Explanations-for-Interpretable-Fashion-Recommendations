## Conventions and readings

- Guarded cosine: cos(a,b) = a.b / (max(|a|,1e-8) max(|b|,1e-8)).
- Training row (u, i+, negs): one q_u^LOO (basket H_u minus i+, mean over |H_u|-1, word part 0 if empty) feeds u* and u^ for every candidate of the row; negatives drawn from items outside H_u.
- Gradient tests use each loss with and without the inclusion regularisers (0.3 R_proto_item - 0.2 R_batch_item + 0.25 R_proto_user + 0.15 R_batch_user over the row batch).
- 'Exactly' / 'machine precision': relative error <= 1e-11 in float64, where the denominator is the magnitude of the operands that enter the computation (so pure floating-point cancellation is not mistaken for a failure; where a kappa factor is applied it is stated). 'Bit-identical' is tested with torch.equal in float64 and float32.
- 'Differs generically': relative difference > 1e-9 on random instances (float64 rounding noise in these tests is <= ~1e-13, so 1e-9 separates a genuine difference from noise even at mixed scales where the true difference is ~1e-7 relative).
- Shapes (fields' vocab sizes, M, N, d, K_u, K_t): A: (4, 5, 3), 14, 7, 6, 3, 4; B: (6, 7), 20, 9, 4, 5, 2; C: (3, 3, 4, 2), 11, 6, 9, 2, 6. Word ids are randomly permuted across fields. Bag layout: k_{i,phi} uniform in 0..min(6,|V_phi|) (distinct words); 'bagms' = bag layout with word multisets (k_{i,phi} in 0..6 drawn with replacement, so a word can repeat inside an item); baskets 1..6 items unless stated. Layout sets: fixed/bag/bagms wherever a claim is not restricted to the fixed layout.
- Seeds 0-5 (subsets where noted); scale sets: unit, all 1e-3, all 1e3, mixA (E_w 1e3, ID 1e-3, P 1, W_u 1e-3, W_t 1e1), mixB (E_w 1e-3, ID 1e3, P 1e3, W_u 1e3, W_t 1e-3), all-negative entries, random per-block scale in 1e-3..1e3.
