# Paper Re-Read Workflow

## Process
1. Claude reads the paper section, prepares questions in a markdown file
2. User answers in the file
3. Claude evaluates, writes evaluations back into the same file
4. Move to next section

## Instructions
- Tackle each subsection separately (3.1, 3.2, 3.3, etc.)
- Questions should be answerable within the section (or using prior sections)
- No fixed number of questions — determine based on what's sensible and important
- Questions prepared before user answers, not interleaved
- Evaluations go back into the document inline after each answer

## File naming
`0X_<topic>.md` (e.g., `03_methodology_3.1_u_protomf.md`)
